We count a gain only when it beats the noise

Testing Unlock on a laptop, a change first looked like +57% CPU speed. Measured again A/B/A/B, it was the cold first run, not the change. So every measurement now starts with an uncounted warm-up, takes the median of five rounds, and calls a change faster only when it beats the spread between rounds.

How it works

Your machines. Your data. One platform.

A small agent runs on each machine: Windows, Linux, macOS or WSL, CPU or GPU. It only makes outbound HTTPS calls, so nothing on the machine is opened to the internet.

The platform queues the work, the agent measures, tunes or changes settings on the machine, and the results come back as runs you can compare, report and publish when you choose.

Each customer gets a dedicated instance with its own data, hosted by us or installed in their own network.

Offloader

Spend cloud tokens only where they count.

Model Offloader

Sits beside your copilot or chat tool. Repeated questions come from a cache, easy ones go to a local open model, and only hard ones reach a paid cloud model. It reports what it saved.

# on the machine
python -m offloader serve --port 8787

colibri

An open-source engine that runs mixture-of-experts models far larger than RAM: hot experts on the GPU, warm ones in RAM, cold ones streamed from disk. CPU-LLM measures it on your machines and checks whether a model fits before you download it.

colibri is an independent project by JustVugg, under the Apache-2.0 licence. CPU-LLM is not affiliated with it.

The speed you paid for. Changed safely, proved.

AreaWhat Unlock checksWhat it does

No software can switch on cores fused off in the chip, and Unlock never touches firmware or drivers. gpu-unlock is an independent GPL-2.0 project by Zagitta for GeForce RTX 20, 30 and 40 cards on Linux; check NVIDIA's licence terms before using it at work.
